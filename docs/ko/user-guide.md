# NanumPlayer 사용자 가이드

[English](../user-guide.md) · 한국어

이 가이드는 설치부터 고급 기능까지 NanumPlayer를 차례로 안내합니다. 메뉴 이름은 한국어 인터페이스에 표시되는 그대로 적었으며,
영어 표기와의 대응은 [용어집](../glossary.md)에 있습니다. 설정과 데이터 위치는 [개인정보](privacy.md#데이터가-있는-위치)에, 명령행 옵션은
[레퍼런스](reference.md)에 정리되어 있습니다.

## 설치

[Releases 페이지](https://github.com/kimmingul/NanumPlayer/releases/latest)에서 `NanumPlayer-Setup-<version>.exe`(또는 포터블 ZIP)를
내려받아 `SHA256SUMS-<version>.txt`와 대조해 확인합니다(SmartScreen 안내는 [README](../../README.ko.md#다운로드)를 참고하세요).

설치 파일은 현재 사용자 단위로 설치합니다. 선택 작업은 모두 기본적으로 **선택 해제**되어 있으며,
선택하지 않으면 아무것도 다운로드하지 않습니다.

| 작업 | 다운로드하는 내용 |
|---|---|
| 영어 음성 인식: Whisper small.en + Silero VAD | 영어 음성 모델과 VAD 모델(약 466 MiB). |
| 다국어 음성 인식: Whisper small + Silero VAD | 다국어 음성 모델과 VAD 모델(약 466 MiB). |
| 다국어 고정밀 음성 인식: Whisper large-v3-turbo + Silero VAD | Whisper large-v3-turbo(q5_0)와 VAD 모델(약 548 MiB). 설치하면 영어가 아닌 음성에는 small 모델 대신 이 모델을 사용합니다. |
| 음성 감지 모델만: Silero VAD | VAD 모델(약 0.8 MiB). |
| NVIDIA CUDA 가속: cuBLAS 받기 | 호환되는 CUDA 13 Toolkit이 없을 때 cuBLAS(약 507 MiB). 먼저 NVIDIA 약관에 동의해야 합니다. |
| YouTube 재생 구성 요소: yt-dlp + Deno | YouTube 재생용 `yt-dlp`와 Deno. |
| Blu-ray/DVD 복호화 구성 요소 | 선택 사항이며 별도 구성 요소입니다. [디스크 구성 요소](disc-components.md)를 참고하세요. |

*준비* 화면에는 이미 있는 항목(설치된 모델은 이미 설치됨으로 표시되며 다시 받지 않습니다)과 없는 항목(음성 모델, CUDA Toolkit,
드라이버와 GPU, YouTube 도구, WebView2 런타임, Ollama)이 표시됩니다. 정보만 보여 줄 뿐 스스로 아무것도 설치하지 않습니다.

모든 다운로드는 정확한 URL, 크기, SHA-256에 고정되어 있으며 검증을 통과해야 사용합니다. 모델은 `%LOCALAPPDATA%\NanumPlayer\models`에
저장되고, 재설치할 때 재사용하며, 앱을 삭제해도 유지됩니다. 무인 설치: `/TASKS=`는 선택 다운로드 없이 설치하고,
`/TASKS=cuda_accel`은 cuBLAS 다운로드를 요청하며 함께 제공되는 NVIDIA 약관에 동의한 것으로 처리합니다. 요청한 다운로드가
실패하면 조용히 성공하지 않고 오류와 함께 설치가 실패합니다.

포터블 ZIP은 설치가 필요 없습니다. 모델과 도구는 같은 `%LOCALAPPDATA%\NanumPlayer` 폴더로 필요할 때 내려받습니다.

## AI 자막 설정

AI 자막에는 세 가지가 필요합니다. 텍스트의 출처(음성 인식 또는 기존 텍스트 자막), 번역 서버, 그리고 음성 인식을 위한 음성 모델입니다.

### 1. 번역 서버

NanumPlayer는 Ollama 호환 `/api/generate` 엔드포인트(기본값 `http://127.0.0.1:11434`)로 텍스트를 보냅니다.
[Ollama](https://ollama.com)를 설치하고 실행(`ollama serve`)한 뒤 모델을 받거나, 로그인해서 Ollama 클라우드 모델을 사용하세요.

모델은 **Ctrl+N → 번역 모델**에서 고릅니다. 목록에는 서버가 알려 주는 모델이 표시됩니다. 로컬 모델은 크기와 파라미터 수와 함께,
클라우드 모델은 그렇게 표시되어 나타납니다. 서버에 연결할 수 없거나 모델이 목록에 없으면 이름을 직접 입력하세요.
다른 서버 주소는 `--nanum-translate-endpoint`로 지정할 수 있습니다(빈 값은 번역을 끕니다).

모델 크기가 중요합니다. 기본 이름인 `gemma4:latest`는 12.8 GB로, 8 GB GPU에서는 일부만 올라가고 음성 인식과 영상 렌더러와
자원을 다투므로 번역이 시간 초과될 수 있습니다. 4 GB급 모델은 150초 샘플의 24줄 중 24줄을 번역했고 마지막 줄이 12초 늦었습니다.
실시간으로 쓸 만하지만 일부 고유명사와 감탄사를 놓칩니다. 클라우드 모델은 더 빠르고 더 잘 번역합니다. 측정값은
[검증 기록](../development/verification-history.md)을 참고하세요.

서버가 실행 중이 아니면 모든 번역이 실패하지만 사라지는 것은 없습니다. 실패한 줄은 원문 그대로 표시되고, 상태 칩이 서버에 연결할 수 없다고 알려 줍니다.

### 2. 음성 모델과 AI 구성 요소 관리

음성 인식에는 해당 언어의 Whisper 모델과 Silero VAD 파일이 필요합니다. 설치 중 다운로드를 건너뛰었다면
**Ctrl+N → AI 구성 요소 관리**를 여세요.

- 모든 모델을 한 번에 받거나 하나씩 받을 수 있습니다. Whisper 모델을 선택하면 VAD 파일도 함께 받습니다.
- 진행률, 무결성 검사, 오류, **취소**가 표시됩니다. 메뉴를 닫아도 다운로드는 중단되지 않습니다.
- 모델이 없거나 AI가 꺼져 있으면 자막을 기다리지 않고 바로 재생을 시작합니다. 다운로드가 끝난 뒤 처음 여는 파일부터 음성 인식을 사용합니다.
  재시작은 필요하지 않습니다.
- 사용자 지정 모델 경로와 기존 앱 폴더에서 찾은 모델은 덮어쓰지 않습니다.

영어 음성은 영어 모델을 사용하고, 그 밖의 모든 언어는 다국어 모델(설치되어 있으면 large-v3-turbo)을 사용합니다. 언어 태그가 없는 음성(웹 영상에 흔함)은
다국어 언어 자동 감지로 시작합니다.

### 3. 가속

**Ctrl+N → AI 구성 요소 관리**(또는 **AI 가속 모드** 항목)에서 모드를 선택합니다.

| 모드 | 동작 |
|---|---|
| 자동 | 사용할 수 있으면 CUDA, 아니면 CPU. |
| CPU | CPU만 사용. |
| CUDA 필수 | 음성 인식에 CUDA를 사용하거나, 사용할 수 없는 이유를 알립니다. 재생은 AI 자막 없이 계속됩니다. |

CUDA 엔진(`nanum_ai_cuda.dll`, 약 53 MiB)은 앱에 포함되어 있으며 로드하기 전에 크기와 SHA-256으로 검증합니다. compute capability 8.6 이상의
NVIDIA GPU, 호환 드라이버, 그리고 **CUDA 13 Toolkit**의 cuBLAS가 필요합니다(CUDA 12로는 부족합니다). Toolkit은 설치된 위치에서 그대로 읽으며,
`CUDA_PATH`/`CUDA_PATH_V13_*`, 레지스트리 환경 변수, `%ProgramFiles%\NVIDIA GPU Computing Toolkit\CUDA\v13.*`(최신 버전 우선) 순으로 찾습니다.
Toolkit과 호환 GPU가 있으면 자동 모드는 추가 다운로드나 안내 없이 첫 파일부터 GPU를 사용합니다. Toolkit이 없으면 cuBLAS만(약 507 MiB, NVIDIA 약관 적용)
`%LOCALAPPDATA%\NanumPlayer\accelerators\cuda\13`에 받을 수 있으며, 앱을 업데이트하거나 삭제해도 유지됩니다.

CUDA가 없어도 CPU 음성 인식이나 번역이 꺼지지 않습니다. 텍스트 자막 번역은 음성 모델도 CUDA도 전혀 필요하지 않으며,
"CUDA 필수"는 음성 인식에만 적용됩니다. 모드 변경이나 다운로드는 다음에 여는 파일부터 적용됩니다.

## 재생하기

| 동작 | 방법 |
|---|---|
| 파일 열기 | **Ctrl+O**, 또는 파일을 창으로 끌어다 놓기. |
| Blu-ray 또는 DVD 열기 | **Ctrl+D**, 또는 `NanumPlayer.exe bd://longest --bluray-device=E:` / `dvd:// --dvd-device=E:`([디스크](#디스크)). |
| YouTube | **Ctrl+Y** 또는 **YouTube 주소로 재생…**([YouTube와 웹페이지](#youtube와-웹페이지)). |
| 아무 웹페이지의 영상 | **Ctrl+Shift+Y** 또는 **웹페이지에서 재생하기** 버튼. |

영상을 클릭하면 일시정지하고, 더블 클릭하면 전체 화면을 전환합니다(**F**도 같습니다). 재생 바는 마우스가 멈춘 뒤 1.2초 후에 숨겨지며
(**Ctrl+N → 재생 바 자동 숨김**에서 짧게, 보통, 길게를 고를 수 있습니다), 커서가 창 밖으로 나가면 즉시 숨겨집니다. 일시정지 중이거나
커서가 재생 바 위에 있는 동안에는 유지됩니다. 시작 화면과 재생 바에는 앱 버전이 표시됩니다.

### 탐색 후가 아니라 시작할 때 기다립니다

파일을 열면 NanumPlayer는 처음 30초(*프리롤*)의 자막이 준비될 때까지 기다린 뒤 재생을 시작합니다. 그 뒤로는 타임라인이나 방향키로 탐색해도
AI 자막을 기다리지 않고 재생 또는 일시정지 상태를 유지합니다. 아직 처리되지 않은 구간의 자막은 조금 늦게 도착할 수 있습니다.
**Ctrl+K**로 자막이 얼마나 앞서 있는지 볼 수 있습니다.

선읽기가 자막의 여유 시간을 만들어 줍니다. 플레이어가 이미 버퍼링한 오디오에서 음성을 인식합니다. 설정은
[레퍼런스](reference.md#선읽기)를 참고하세요.

### 상태 태그

재생 바 위의 태그는 선택한 AI 자막 트랙이 어떻게 만들어지는지 보여 줍니다. GPU 또는 CPU의 음성 인식, 원문 모델이나 출처(예: `small.en`,
`large-v3-turbo`, 자막 기반, 디스크 자막 OCR), 그리고 *로컬 GPU*, *로컬 GPU 일부*, *로컬 CPU*, *클라우드* 중 하나로 표시되는 번역 모델입니다.
누르면 해당 설정으로 이동합니다. **Ctrl+N → AI 정보 태그 표시**로 끌 수 있습니다.

## 자막

재생 바의 **자막** 버튼 또는 **Ctrl+N**(*자막* 항목)에서 목록을 엽니다.
(**Ctrl+T**는 파일 자체 트랙만 보여 주는 기본 목록을 엽니다.)

### 자막 목록

하나의 목록에 모든 자막이 출처 배지와 함께 표시됩니다.

| 배지 | 의미 |
|---|---|
| `[AI]` | NanumPlayer가 목표 언어로 만든 자막. 표시 방식이 이 항목에 적용됩니다. |
| `[원본 자막]` | 디스크, 파일 또는 YouTube 업로더가 제공한 자막으로, 그대로 표시합니다. |
| `[파일]` | 영상과 같은 이름으로 옆에 있는 자막 파일(`name.srt`, `name.ko.srt`) 또는 직접 불러온 파일. |
| `[OCR]` | 문자 인식으로 읽은 디스크 이미지 자막. |

- AI 항목의 **표시 방식**: *번역만*(기본), *번역+원문*, *원문만*. 바꿔도 음성 인식이나 번역을 다시 실행하지 않습니다.
  번역하지 못한 줄은 *번역만*에서도 화면이 비지 않도록 원문으로 표시합니다.
- 미디어에 **목표 언어**의 원본 자막(강제 자막, 해설, YouTube 자동 생성 자막은 제외)이 있으면 NanumPlayer가 자동으로 선택하고 그 파일의
  AI 작업을 건너뜁니다. **목표 언어 원본 자막이 있으면 바로 표시**로 끌 수 있습니다. AI 항목을 선택하면 현재 위치부터 AI 작업을 다시 시작합니다.
- `[원본 자막]` 또는 `[파일]` 자막을 직접 선택하면 언어와 상관없이 AI 작업(음성 인식, OCR, 원어 음성)이 일시 중지되고,
  AI 항목을 다시 선택하면 재개됩니다.
- 디스크 재생 중 내장 자막을 선택하면 현재 위치부터 다시 읽어 즉시 나타나게 합니다.
- YouTube에서는 `yt-dlp`에 목표 언어와 영어의 업로더 자막을 요청합니다(자동 생성 자막은 요청하지 않습니다).

### 목표 언어

**Ctrl+N → 번역 목표 언어**에서 33개 언어 중에서 고르거나 이름을 직접 입력합니다(모델이 알아듣는 언어 이름이면 됩니다. 예: *Italian*).
기본값은 Windows 표시 언어입니다. 인식된 언어가 목표 언어와 같으면 번역하지 않고 원문을 표시합니다. 변경은 다음에 여는 파일부터 적용되며,
번역 말투와 용어집은 즉시 적용됩니다.

### 두 가지 음성 입력: 재생 음성과 AI 입력 음성

듣는 음성과 AI가 읽는 음성은 별개입니다. 다른 음성 언어로 바꾸면 NanumPlayer가 **유지**(기존 AI 입력 유지, 기본값), **AI 자막 새로 생성**(새 음성으로),
**저장 자막 다시 조회**(새 음성의 저장된 자막) 중에서 묻습니다. 더빙 음성과 원어 음성은 표현과 타이밍이 달라서 한쪽에서 만든 자막이 다른 쪽에 맞지 않을 수 있습니다.

음성 언어가 여러 개인 영화(예: 영어와 일본어 음성이 있는 Blu-ray)에서는 NanumPlayer가 먼저 재생 음성으로 자막을 만듭니다. 그다음 낮은 우선순위로,
같은 읽기에서(추가 디스크 접근 없이) 원어 음성으로 자막을 만듭니다. 두 트랙으로 나타나며 예를 들어 "한국어 (영어 음성 기반)"와 "한국어 (일본어 음성 기반)"입니다.
원어는 작품 제목(디스크 이름, 제목 태그 또는 파일 이름)과 음성 언어를 번역 모델에 물어서 찾습니다. 실패했을 때 음성 언어가 정확히 두 개이면
재생하지 않는 쪽을 사용합니다. 두 번째 입력은 첫 번째 입력이 재생 위치보다 30초 이상 앞서 있거나 유휴일 때만 동작합니다.
**Ctrl+N → 원어 음성으로도 자막 만들기**로 끌 수 있습니다. *번역+원문*은 각 트랙 고유의 원문을 보여 줍니다.
재생 도중에 켜면 이미 선읽기한 구간(약 2분)은 건너뛰며, 나중에 탐색하면 그 구간을 다시 읽고 분석합니다.

### 텍스트 자막을 원문으로 사용

AI 자막의 원문은 음성 인식이거나 **텍스트 자막 트랙**(SRT, ASS, mov_text, WebVTT; 내장 또는 외부)입니다. 이미지 자막(PGS 등)은 따로 처리합니다(아래 OCR 참고).
NanumPlayer가 자동으로 선택합니다.

- 음성 언어가 L이고 L의 텍스트 자막이 있으면 그것을 사용하고, 없으면 음성 인식을 사용합니다. (영어 자막만 있는 일본 영화는 일본어 음성으로 인식합니다.)
- L을 알 수 없으면 영어, 일본어, 스페인어, 프랑스어 순으로 텍스트 자막을 찾고, 없으면 음성 인식을 사용합니다. 강제 자막과 해설 트랙은 무시합니다.
- **Ctrl+N → 입력 소스**에서 자동, 음성 인식, 특정 자막 트랙 중에서 바꿀 수 있으며 현재 위치부터 다시 시작합니다. 외부 파일은 mpv가 언어를 모를 때
  파일 이름 접미사(`movie.en.srt`)에서 언어를 알아냅니다.

### 자막 가져오기

**Ctrl+N → 자막 파일 가져오기…**(또는 파일을 창으로 끌어다 놓기)는 `.srt`, `.ass`, `.ssa`, `.vtt`, `.sub` 또는 그중 하나를 담은 `.zip`을 불러옵니다.
다음 중에서 고릅니다.

- **그대로 표시.** 파일을 변경 없이 `[파일]` 자막으로 사용합니다.
- **AI로 시간 맞추고 번역.** NanumPlayer가 인코딩(UTF-8, UTF-16, CP949, Shift-JIS, CP1252)과 언어를 감지하고, 큐 시간을 음성 인식 자막의 시작 부분과
  비교해 오프셋(최대 ±240초)과 프레임 레이트 비율(23.976/24/25 fps 변환)을 보정합니다. 신뢰도가 낮으면 아무것도 옮기지 않고 알려 주며,
  ±0.1초와 ±1초 조정 항목으로 직접 보정하세요. 한국어 자막은 그대로 두고, 다른 언어는 아래의 말투와 용어집으로 번역합니다.

새로 가져온 자막은 이전에 가져온 자막을 대체합니다. 작업용 사본은 종료할 때 삭제되며, 내려받은 파일은 절대 삭제하지 않습니다.
영상과 같은 이름으로 옆에 있는 자막 파일은 자동으로 불러옵니다.

### 온라인 자막 찾기

**Ctrl+N → 온라인 자막 찾기 (OpenSubtitles · Jimaku)**는 작품 제목으로 브라우저에서 검색 페이지를 엽니다. OpenSubtitles는 영어, 일본어, 한국어를 다루고,
Jimaku는 일본 애니메이션용입니다(주소 검색이 없어 홈페이지를 열고 검색어를 클립보드에 복사합니다). NanumPlayer는 사이트를 자동으로 조작하지 않습니다.
자막은 직접 내려받으며, 20분 동안 NanumPlayer가 다운로드 폴더(메뉴에서 변경 가능, 기본값은 Windows 다운로드 폴더)에서 `.srt`, `.ass`, `.ssa`, `.vtt`, `.sub`
또는 `.zip` 파일을 지켜보다가 새 파일을 가져옵니다. 가져온 자막은 위와 같이 시간을 맞추고 번역합니다. 사이트마다 컷과 편집이 달라서
자동 정렬의 신뢰도가 낮다고 나올 수 있습니다.

### 이미지 자막(PGS)과 OCR

이미지 자막이 있는 디스크는 NanumPlayer가 같은 디먹서에서 자막 패킷을 디코딩하고(추가 디스크 읽기 없음), 작은 글자를 확대한 뒤 **Windows OCR**(모델은 포함하지 않음)로
읽고 번역합니다. 트랙 이름은 예를 들어 "한국어 (영어 디스크 자막 기반)"이며 `[OCR]` 배지가 붙습니다. 영어 강제가 아닌 트랙을 우선합니다.
영어 OCR 언어 팩이 없으면 설치된 라틴 문자 인식기(예: 한국어 Windows의 `ko`)를 사용하고 흔한 오인식을 보정합니다(`50`→`So`, `donlt`→`don't` 등).
정확도를 높이려면 **Ctrl+N → 영어 OCR 언어 팩 설치 (관리자 권한)**에서 영어 팩을 설치하세요. 일본어 트랙에는 일본어 팩이 필요합니다.
결과는 현재 재생 동안만 유지됩니다. `nanum-pgs`로 끌 수 있습니다([레퍼런스](reference.md) 참고).

### 용어집과 번역 말투

NanumPlayer는 번역 모델에게 작품 제목(디스크 이름, 제목 태그 또는 파일 이름)으로 작품을 파악하게 하고, 등장인물(성, 이름, 전체 이름), 장소, 조직, 용어의 용어집을 만듭니다.
각 항목에는 목표 언어 표기가 하나씩 있습니다. 용어집은 실시간 번역(해당 줄에 나오는 항목과 주요 등장인물)과 전체 번역(용어집 전체)에 추가됩니다.

**Ctrl+N → 용어집**에서 목록을 보고 항목을 추가, 변경, 삭제하거나, **메모장에서 한꺼번에 편집**하거나, **AI로 다시 만들기**를 할 수 있습니다. 이름 하나를 바꾸면 같은 인물의 성, 이름, 전체 이름도
함께 바꿀지 묻습니다. 변경한 뒤에는 그 이름이 들어 있는 모든 기존 자막(두 트랙, 저장된 사본, 전체 번역)을 한꺼번에 다시 번역합니다.

품질은 모델에 따라 달라집니다. 작은 로컬 모델은 모르는 인물의 항목을 지어낼 수 있으니, 목록을 훑어보고 틀린 부분을 고치세요. 용어집을 편집하면 NanumPlayer가 작품 이름으로 된 텍스트 파일을 `%APPDATA%\NanumPlayer\glossary`에 저장합니다([개인정보](privacy.md#데이터가-있는-위치) 참고).

**Ctrl+N → 번역 말투**: *자연스럽게 (기본)*(등장인물의 관계에 맞춰 존댓말과 반말을 일관되게 유지), *존댓말*, *반말*, *원문에 충실*, 또는 직접 지시문을 쓰는 *사용자 지정*.
변경은 그때부터 번역되는 모든 것에 적용되며, 캐시는 말투와 용어집별로 유지됩니다.

### 전체 파일("전체") 번역

**전체 번역**을 켜면 별도의 리더가 원문 전체를 모아 용어집을 사용해 60줄 창(5줄 겹침) 단위로 번역하고, `.ass` 파일을 임시 폴더에 씁니다.
끝나면 해당 트랙이 선택됩니다. 엔진은 Ollama(기본값, 실시간 번역과 같은 서버와 모델) 또는 **omp**(oh-my-pi, 이미 로그인한 모델을 사용하며 메뉴에
`omp models --json`의 목록이 표시됩니다)입니다. omp는 호출당 수 초가 걸리므로 실시간 번역은 항상 Ollama를 사용합니다.

**광디스크**에서는 전체 파일 리더가 두 번째 읽기 위치이므로 재생과 스캔이 서로를 느리게 할 수 있습니다. 스캔은 10초 지점에서 시작하고 엔진보다 90초를 넘게 앞서가지 않습니다.
로컬 파일에서는 문제가 되지 않습니다.

### 저장된 자막

기본적으로 자막은 현재 재생 동안만 보관되고 다음에 다시 만듭니다. `--nanum-library-db=<path>`를 지정한 경우에만 NanumPlayer가 영화별 라이브러리(원문 전사와 시간,
번역, 모델, 목표 언어, 작업 상태)를 SQLite 파일에 보관하여, 다시 열면 즉시 사용할 수 있고 **저장된 원문에서 다시 번역**할 수 있습니다. 파일은 크기와
SHA-256 콘텐츠 지문으로 식별합니다(16 MiB까지는 파일 전체, 그보다 큰 파일은 양 끝 4 MiB와 256 KiB 샘플 열여섯 개이므로 샘플 밖의 변경은 눈치채지 못할 수 있습니다).
이동한 파일은 알아보지만 경로만 같은 파일은 알아보지 못합니다. Blu-ray 디스크는 libbluray의 디스크 ID, 볼륨, 제목 또는 플레이리스트, 클립과 트랙으로 식별하며
드라이브 문자만으로는 식별하지 않습니다. 웹 미디어는 라이브러리에 저장하지 않습니다. [개인정보](privacy.md)를 참고하세요.

## 재생 없이 자막 파일 만들기

**Ctrl+N → 전체 자막 생성…**(창 이름 "자막 파일 만들기")은 로컬 영상이나 Blu-ray 제목의 자막 파일을 **재생하지 않고** 만듭니다. 별도의 디먹서가 필요한
스트림만 최고 속도로 읽으며(화면도 소리도 출력하지 않음) 시청 중인 영상을 방해하지 않습니다. 원본을 고릅니다.

- 오디오 트랙의 **음성 인식**(CPU 또는 CUDA 엔진).
- **텍스트 자막 트랙** 또는 외부 자막 파일.
- **이미지 자막 트랙의 OCR**(PGS 또는 DVD), Windows OCR 사용.

원문 언어 SRT를 먼저 저장하고, 이어서 선택한 언어마다 번역된 SRT를 하나씩 저장합니다. 번역에는 사용자의 서버, 모델, 말투, 용어집을 사용합니다. 원문이 이미 가진 언어는 다시 번역하지 않습니다.
진행률과 경과 시간은 메뉴와 알림에 표시되며, **취소**하면 이미 쓴 파일은 남깁니다. 파일 이름은 영상 옆에 `<video name>.<language>.srt`로 붙입니다(디스크는
`%USERPROFILE%\Videos\NanumPlayer` 또는 선택한 폴더). 기존 이름은 절대 덮어쓰지 않고 `.2`, `.3`을 붙입니다. 각 파일은 `.part`로 쓴 뒤 이름을 바꾸므로 중단된 작업이
반쯤 쓰인 파일을 남기지 않습니다. **처음 10분만 (미리보기)**로 OCR 팩과 번역 품질을 먼저 확인할 수 있습니다. 시작하지 않으면 아무것도 쓰지 않으며, 끝난 뒤에는 아무것도 기억하지 않습니다.

디스크 이미지 자막의 OCR은 제목 전체를 읽으므로 광학 드라이브만큼 느립니다. 웹 영상은 이 기능에서 지원하지 않으니 재생하면서 AI 자막을 사용하세요. 스크립트로 쓰려면
[레퍼런스](reference.md#자막-파일-생성)를 참고하세요.

## 영상 화질

### GPU 업스케일

**Ctrl+N → 영상 업스케일 → 방식.** CUDA 음성 인식과는 별개이며 CUDA Toolkit이 필요하지 않습니다.

- **기본**: 추가 처리를 하지 않으며, 이 기능이 바꾼 렌더러와 스케일러 설정을 복원합니다. 사용자 고유의 필터와 셰이더는 유지합니다.
- **고품질 크기 조정**: GPU 렌더러에서 링잉 억제 0.6의 `ewa_lanczossharp`. AI 방식이 아닙니다.
- **NVIDIA RTX 업스케일**: `gpu-next`, D3D11, D3D11VA와 `d3d11vpp`의 NVIDIA 확장을 사용합니다. 지원되는 NVIDIA GPU와 드라이버가 필요하며 NVIDIA 앱이나
  제어판에서 RTX Video Super Resolution을 켜 두어야 합니다. 상태의 "요청됨"은 필터를 요청했다는 뜻이며, 드라이버가 AI 처리를 하고 있다는 증거는 아닙니다.
- **사용자 셰이더**: mpv 호환 `.glsl`, `.hook`, `.frag` 파일을 하나씩 추가하며, 항목을 선택해 순서를 바꾸거나 제거할 수 있습니다. Anime4K나 FSRCNNX 같은 셰이더 팩은 포함되어 있지 않습니다.
  기존 셰이더 뒤에 선택한 순서대로 적용됩니다.

RTX 배율은 **자동 / 1.5x / 2x / 3x**입니다. 자동은 원본과 창 크기로 계산하며 0.25 단위로 올림하고 최대 4배로 제한하며, 확대가 필요 없으면 필터를 제거합니다. 창 크기 변경은 잠시 멈춘 뒤 적용됩니다.
고정 2x는 가로와 세로를 두 배로 만듭니다(1080p → 4K). 이미 4K인 원본이나 창보다 큰 원본에는 고정 배율을 적용하지 마세요.

선택은 재생 중에 적용되며 `~~/script-opts/nanum-upscale.conf`(기본값 `%APPDATA%\NanumPlayer\script-opts`)에 저장됩니다. 렌더러를 바꾸면 화면 내용이 잠깐 다시 만들어질 수 있습니다.
지원되지 않는 GPU나 셰이더 컴파일 오류는 상태에 표시되며 이 기능이 추가한 처리는 제거됩니다. RTX HDR 변환은 켜지 않으며, HDR과 10비트 지원은 드라이버와 영상 경로에 따라 다릅니다.
음성 인식, 로컬 번역 모델, 업스케일은 같은 GPU를 두고 경쟁하므로 프레임 드롭이 늘 수 있습니다. 배율을 낮추거나 고품질 크기 조정과 비교해 보세요.

### 내장 영상 화질 보정

**Ctrl+N → 영상 화질**. 프리셋: **원본**(기본값, 보정 없음), **애니 선명하게**, **옛날 애니 부드럽게**, **압축 영상 보정**. AI 모델도 다운로드도 쓰지 않고,
직접 작성한 가벼운 GPU 셰이더 아홉 개(합계 약 12.3 KiB)와 mpv의 내장 기능만 사용하며, 외부 Anime4K 팩과는 무관합니다.

| 항목 | 하는 일 |
|---|---|
| 노이즈 줄이기 | 윤곽을 보존하는 공간 필터로 평평한 영역의 작은 노이즈를 제거합니다. 강하게 하면 배경 질감이 지워질 수 있습니다. |
| 색 띠 완화 | 그라데이션의 계단을 줄입니다. |
| 선 강조 / 선명도 | 어두운 선을 약간 더 어둡게 하거나, 주변 픽셀 범위 안에서 선명하게 합니다. AI로 선을 다시 그리지 않습니다. |
| 색 보정 | 기존 채도와 대비를 약간 높입니다. 원래 색을 추정하지 않습니다. |

각 항목은 **끔 / 약함 / 중간 / 강함**이며, 개별 변경은 사용자 지정 조합으로 저장됩니다. **보정 전 화면 비교**는 이 보정만 일시적으로 끄며, 업스케일과 사용자 필터는 그대로 유지되고
비교 상태는 저장되지 않습니다. **원본**을 선택하면 보정이 꺼지고 그 선택이 저장됩니다.

RTX 모드에서는 이중 선명화를 피하기 위해 선 강조와 선명도가 **일시 중지**되고, RTX를 벗어나면 선택했던 강도로 돌아갑니다. 노이즈 줄이기, 색 띠 완화, 색 보정은 함께 동작할 수 있습니다.
플레이어는 사용자 셰이더가 무슨 일을 하는지 알 수 없으므로 선명화가 겹치지 않게 하세요.

`gpu-next` 또는 `gpu` 출력이 필요하며 `~~/script-opts/nanum-picture.conf`에 저장되고, 다른 곳에서 만든 필터와 설정은 그대로 둡니다. 지원되지 않는 출력과 셰이더 오류는
메뉴에 표시됩니다. 이들은 실시간 공간 필터입니다. 시간 축 깜빡임 제거, AI 재채색, 애니메이션 화풍 변환은 없습니다. HDR이나 고해상도 영상에서 AI 자막을 동시에 쓸 때는
결과와 재생 부하를 원본과 비교해 보세요.

## 디스크

NanumPlayer는 플레이어 프로세스 안에서 Blu-ray와 DVD를 재생합니다. 암호화되지 않은 디스크와 디스크 폴더(`BDMV`)는 추가 구성 없이 동작합니다. 복사 방지가 걸린 디스크는
[디스크 구성 요소](disc-components.md)를 참고하세요. 복호화 라이브러리는 선택적인 별도 설치입니다.

- **열기:** **Ctrl+D** 또는 시작 화면 카드, 또는 `NanumPlayer.exe bd://longest --bluray-device=E:`, `NanumPlayer.exe dvd:// --dvd-device=E:`.
  Blu-ray 폴더를 창으로 끌어다 놓을 수도 있습니다.
- **자막용 선읽기:** 디스크에서 AI 자막을 쓰려면 `--demuxer-readahead-secs=120 --demuxer-max-bytes=1500MiB`를 사용하세요. 최대 48 Mbit/s의 Blu-ray 먹스에서 120초는 약 720 MB입니다.
- **MKV로 저장:** **Ctrl+B → 드라이브 → 제목 / 모든 제목**은 `%USERPROFILE%\Videos\NanumPlayer`에 무손실 MKV 파일을 씁니다. 2분 이상인 제목이 나열되며,
  기본 앵글의 영상, 음성, 자막, 챕터를 재인코딩 없이 복사합니다. **Ctrl+C**는 진행 중인 저장이나 검색을 취소하고 완성되지 않은 파일만 제거합니다.
  기존 이름은 절대 덮어쓰지 않고 번호를 붙입니다. DVD는 없는 영상 타임스탬프를 FFmpeg로 다시 만들고, 다음 제목으로 넘어가는 명령은 실제 제목 경계에서 자릅니다.
- **진단:** 상세 디스크 로그는 기본적으로 꺼져 있습니다. [문제 해결](troubleshooting.md#디스크-읽기와-탐색-진단)을 참고하세요.

## YouTube와 웹페이지

### YouTube

**Ctrl+Y**(또는 시작 화면의 **YouTube** 버튼)를 누릅니다. 내장 브라우저 창(WebView2, `nanum_youtube.exe`)이 열리면 평소처럼 영상을 고르고 로그인합니다.
그러면 NanumPlayer가 그 창의 쿠키를 사용해 `yt-dlp`(Deno와 함께, 둘 다 SHA-256으로 확인하고 업데이트를 확인하는 선택 다운로드)를 통해 재생하며,
같은 AI 자막, 용어집, 말투 등을 제공합니다. 영상에 업로더 자막이 있으면 입력 소스 규칙에 따라 그것을 원문으로 사용합니다(메뉴에서 음성 인식으로 바꿀 수 있습니다).
주소를 붙여넣을 수도 있고(**Ctrl+N → YouTube 주소로 재생…**), `nanumplayer://open?url=` 스킴을 사용해 브라우저 북마크 "NanumPlayer로 열기"를 추가할 수도 있습니다.
비공식 도구로 계정을 사용하면 YouTube가 추가 확인을 요구하거나 계정을 제한할 수 있습니다.

### 아무 웹페이지

1. 시작 화면에서 **웹페이지에서 재생하기**를 선택하거나, **Ctrl+Shift+Y**를 누르거나, **Ctrl+N → 웹페이지 영상 주소로 재생…**을 선택하고 페이지 주소를 붙여넣습니다.
2. 내장 브라우저 창에서 필요하면 로그인하고 **사이트에서 영상을 시작**합니다.
3. 위쪽의 **NanumPlayer에서 재생**을 클릭합니다. 영상과 소리가 NanumPlayer에서 재생되며 평소의 AI 자막 설정(어느 파일과 같은 음성 모델과 번역 서버)이 적용됩니다.

도우미는 iframe에 로드된 미디어와 관찰된 HLS/DASH 매니페스트를 감지하며, 그 영상의 쿠키, Referer, User-Agent는 그 파일에만 적용됩니다. DRM으로 보호된 영상,
재생 가능한 미디어나 매니페스트 URL을 노출하지 않는 페이지, 브라우저 밖의 재생을 거부하는 서버는 동작하지 않습니다. 주소가 만료되면 페이지를 다시 불러오세요.
모든 사이트가 동작한다는 보장은 없습니다.

두 창은 하나의 **시크릿 세션(InPrivate)**을 공유합니다. 로그인은 그 세션 동안만 유지되고, 브라우저 데이터는 종료할 때 제거되며,
**Ctrl+N → YouTube → 시크릿 웹 세션 종료 (로그아웃)**으로 즉시 종료할 수 있습니다. 무엇이 보호되고 무엇이 보호되지 않는지는 [개인정보](privacy.md#시크릿-웹-세션)를 참고하세요.

## 인터페이스 언어와 단축키

인터페이스는 처음 실행할 때 Windows 표시 언어(또는 설치 중에 고른 언어)를 따르며, 지원하지 않는 언어는 영어로 대체됩니다. 시작 화면 오른쪽 위의 언어 버튼,
**Ctrl+Alt+L**, 또는 **Ctrl+N → 인터페이스 언어**로 바꿀 수 있습니다. **자동**을 고르면 다시 Windows를 따릅니다. 선택은 설정 폴더의 `ui-language.conf`에 저장됩니다.
`--nanum-ui-language=es`(`auto`, `ko`, `en`, `ja`, `zh-CN`, `zh-TW`도 가능)는 그 실행에 한해 이를 덮어씁니다. 실행 중인 브라우저 창의 버튼 라벨은 즉시 바뀌고,
WebView2 자체 메뉴는 다음 브라우저 세션부터 새 언어를 사용합니다. 인터페이스 언어는 음성 및 자막 언어와 별개입니다.

| 키 | 동작 |
|---|---|
| Ctrl+N | AI 자막 설정(주 메뉴) |
| Ctrl+K | AI 자막 상태 |
| Ctrl+O | 파일 열기 |
| Ctrl+D | Blu-ray 드라이브 또는 폴더 열기 |
| Ctrl+A | 음성 트랙 패널 |
| Ctrl+T | 기본 자막 트랙 목록 |
| Ctrl+B | Blu-ray 또는 DVD 제목을 MKV로 저장(Ctrl+C로 취소) |
| Ctrl+Y | YouTube |
| Ctrl+Shift+Y | 웹페이지에서 재생하기 |
| Ctrl+Alt+L | 인터페이스 언어 |
| Space / F | 재생·일시정지 / 전체 화면 |
