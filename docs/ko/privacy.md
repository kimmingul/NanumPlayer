# 개인정보

[English](../privacy.md) · 한국어

NanumPlayer는 기본적으로 무엇을 시청했는지에 관한 어떤 것도 남기지 않도록 만들어졌습니다. 이 문서는
무엇이 저장되고, 무엇을 내려받고, 무엇이 PC 밖으로 나가는지 정리하므로 [소스 코드](https://github.com/kimmingul/NanumPlayer)와
대조해 확인할 수 있습니다.

NanumPlayer에는 계정, 원격 측정(텔레메트리)이나 분석, 자동 업데이트 확인이 없으며 자체 서버도 없습니다.
NanumPlayer 자체 코드가 만드는 네트워크 연결은 [플레이어가 내려받고 접속하는 대상](#플레이어가-내려받고-접속하는-대상)에
나열한 것뿐입니다. **Ctrl+N** 맨 아래의 **정보** 항목은 브라우저에서 GitHub 릴리스 페이지를 열 뿐입니다.

## 기본적으로 저장하지 않는 것

명시적으로 켜지 않는 한 다음은 어느 것도 기록되지 않습니다.

- 재생 로그(기본 로그는 꺼져 있음),
- 시청 기록과 이어보기 위치, 방문한 주소와 재생 위치,
- 번역 캐시(JSONL 파일),
- 자막 라이브러리(저장된 자막의 SQLite 파일),
- GPU 셰이더와 색 프로필 디스크 캐시,
- 충돌 덤프.

전체 번역 결과와 자막 가져오기 작업 사본은 실행 중인 프로세스의 임시 폴더
(`%TEMP%\NanumPlayer-session-<pid>-<start time>`)에 있습니다. 이 폴더는 미디어가 끝나면 비워지고,
플레이어가 종료되면 삭제되며, 플레이어가 강제 종료된 경우 다음 시작 때 정리됩니다.

이전 버전이 기본 위치에 남기던 파일(설정 폴더의 `last-playback*.log` 파일, `tr_cache.jsonl`,
`%LOCALAPPDATA%\NanumPlayer\library.sqlite*`, `full\`, `cache\`, `dumps\` 폴더, 오래된 브라우저 프로필)은
해당 옵션을 사용자가 직접 정한 위치로 지정하지 않았다면 새 버전을 처음 시작할 때 삭제됩니다. 모델, 설정,
내려받은 도구, 디스크 키, 사용자가 직접 저장한 영상이나 자막 파일은 절대 건드리지 않습니다.

이를 바꾸는 옵션입니다. 각각 **명시적으로 지정했을 때만** 데이터를 남깁니다.

| 옵션 | 남기는 것 |
|---|---|
| `--log-file=<file>` | mpv의 일반 로그. 주소와 파일 이름이 들어 있을 수 있습니다. 비공개 시청에는 사용하지 마세요. |
| `--nanum-cache=<file>` | 로컬 미디어용 번역 캐시. 웹 미디어에는 사용하지 않습니다. |
| `--nanum-library-db=<file>` | 원문 대본, 시간, 번역, 모델, 번역 목표 언어를 담은 영화별 라이브러리. 웹 미디어에는 사용하지 않습니다. |
| `--nanum-full-dir=<folder>` | 로컬 미디어의 전체 번역 결과. 웹 미디어는 항상 임시 폴더를 사용합니다. |
| `NANUMPLAYER_CRASH_DUMP_DIR` | 충돌 덤프. 주소, 쿠키 등 프로세스 메모리의 내용이 들어 있을 수 있습니다. |
| `NANUMPLAYER_DIAGNOSTICS=1` 또는 **Ctrl+N → 진단 로그(디스크 읽기 상세)** | [문제 해결](troubleshooting.md#디스크-읽기와-탐색-진단)에 설명한 디스크 진단 로그. |

## 데이터가 있는 위치

| 항목 | 위치 |
|---|---|
| 설정(`mpv.conf`, `script-opts\*.conf`, `ui-language.conf`) | `%APPDATA%\NanumPlayer`(*설정 폴더*, mpv 용어로 `~~`) |
| 용어집 파일 | `%APPDATA%\NanumPlayer\glossary\<작품 이름>.txt`와 `<작품 이름>.applied.txt`. 용어집을 편집할 때(메뉴 또는 메모장) 기록되고 그 뒤에도 남으며, 작품 제목을 파일 이름으로 씁니다. 무엇을 봤는지 흔적을 남기고 싶지 않다면 이 폴더를 삭제하세요. 용어집을 편집하지 않으면 여기에는 아무것도 기록되지 않습니다. |
| 진단 로그(켠 경우) | `%APPDATA%\NanumPlayer\diagnostics\` |
| 음성 모델 | `%LOCALAPPDATA%\NanumPlayer\models` |
| cuBLAS 런타임(선택) | `%LOCALAPPDATA%\NanumPlayer\accelerators\cuda\13` |
| YouTube 도구(`yt-dlp`, Deno) | `%LOCALAPPDATA%\NanumPlayer\youtube` |
| 디스크 구성 요소와 AACS 키 데이터베이스(선택, [디스크 구성 요소](disc-components.md) 참고) | `%LOCALAPPDATA%\NanumPlayer` 및 `%APPDATA%\NanumPlayer\disc` 아래 |
| 생성하거나 저장한 자막 파일, 저장한 MKV 파일 | 영상 옆, 또는 `%USERPROFILE%\Videos\NanumPlayer` |

제거해도 모델, cuBLAS 런타임, 설정은 남습니다.

## 플레이어가 내려받고 접속하는 대상

| 시점 | 접속 대상 | 전송하거나 가져오는 것 |
|---|---|---|
| 번역할 때(번역을 켰다면 항상) | 사용자가 설정한 **번역 서버**. 기본값은 사용자 PC의 `http://127.0.0.1:11434` | 번역할 텍스트: 인식된 음성 또는 자막 줄. 용어집에는 작품 제목(디스크 이름, 제목 태그 또는 파일 이름)과 음성 언어도 포함됩니다. Ollama **클라우드** 모델을 쓰면 Ollama가 이 텍스트를 클라우드로 전달하므로 Ollama의 개인정보 약관을 읽어 보세요. 사용자가 고른 서버가 이 텍스트를 어떻게 다루는지는 NanumPlayer가 제어할 수 없습니다. |
| `omp`로 전체 번역할 때 | 사용자가 설정한 `omp` 명령과, 선택한 모델 뒤의 제공자 | 같은 텍스트. |
| 음성 모델을 직접 내려받을 때(설치 파일 또는 **AI 구성 요소 관리**) | Hugging Face의 `ggerganov/whisper.cpp`와 `ggml-org/whisper-vad`(고정된 리비전) | 파일 다운로드. 크기와 SHA-256을 검증합니다. |
| cuBLAS를 직접 내려받을 때 | 이 저장소의 GitHub 릴리스 | 파일 다운로드(검증됨). |
| YouTube 도구를 직접 설치할 때, 그리고 YouTube 재생을 쓸 때 | `yt-dlp`와 `denoland/deno`의 GitHub 릴리스(최신 버전을 찾기 위한 릴리스 API 포함) | 파일 다운로드(검증됨), 버전 확인. |
| YouTube와 웹 창 | 사용자가 방문하는 사이트. WebView2(Microsoft Edge 엔진)를 통해 접속 | 일반적인 브라우징 트래픽. [시크릿 웹 세션](#시크릿-웹-세션)을 참고하세요. |
| YouTube 재생 | `yt-dlp`를 통한 YouTube | 창의 쿠키를 사용한 영상 요청. |
| 웹페이지 영상 재생 | 해당 영상의 서버 | 그 영상의 쿠키, Referer, User-Agent를 사용한 미디어 요청. |
| **온라인 자막 찾기** | 기본 브라우저가 OpenSubtitles 또는 Jimaku를 엽니다 | OpenSubtitles는 제목 검색어가 주소에 나타나고, Jimaku는 클립보드에 복사됩니다. NanumPlayer는 해당 사이트를 제어하지도, 읽지도 않습니다. |
| 선택 디스크 구성 요소를 직접 설치할 때 | 구성 요소 저장소의 GitHub 릴리스, 동의한 경우 FindVUK 공개 키 데이터베이스 | [디스크 구성 요소](disc-components.md)를 참고하세요. |
| **영어 OCR 언어 팩 설치**를 선택할 때 | Windows(Microsoft) | Windows 자체의 언어 팩 설치 프로그램. |

모든 다운로드는 HTTPS 전용 모듈 하나를 거치며, 파일이 고정된 경우 고정 크기와 SHA-256을 검사하고
진행률 표시와 취소를 지원합니다. 실패하거나 취소된 다운로드는 기존의 정상 파일을 건드리지 않고 임시
파일을 삭제합니다.

## 시크릿 웹 세션

YouTube와 웹페이지 창은 항상 **InPrivate** WebView2 세션에서 실행됩니다. 로그인은 해당 세션에서만
유지되며, 세션이 끝나면(또는 **시크릿 웹 세션 종료 (로그아웃)**을 선택하면) 로그인, 쿠키, 브라우저
임시 데이터가 삭제됩니다. 세션 폴더는 브라우저 프로세스가 종료된 뒤 삭제되며, 비정상 종료로 남은
세션은 다음 시작 때 정리됩니다.

- 일반 웹 영상의 쿠키는 도메인과 경로 범위를 유지한 채 메모리 데이터로 플레이어에 전달되며 해당
  파일에만 사용됩니다.
- YouTube 쿠키는 브라우저 세션 임시 파일과, 추출기용으로 플레이어가 소유한 임시 사본을 사용하며
  각각 세션 종료 시 삭제됩니다. `yt-dlp`가 종료하면서 쿠키를 다시 써도 브라우저에서 삭제된 파일은 다시
  만들어지지 않습니다.
- WebView2는 실행 중 임시 파일을 만들 수 있습니다.

**시크릿 모드는 익명성도, 보안 삭제도 아닙니다.** 웹사이트, 통신망 사업자, 번역 서버나 그 제공자에게서
사용자의 트래픽을 숨기지 못하며, 운영체제의 메모리 페이징이나 삭제된 파일의 복구 가능성도 막을 수
없습니다. 사용자의 브라우저에서 여는 검색 페이지(온라인 자막 검색)는 해당 브라우저의 개인정보 설정을
따릅니다.

## 서드파티 도구와 사용자 데이터

음성 인식은 사용자의 PC에서 실행되며(whisper.cpp), NanumPlayer는 어떤 오디오도 업로드하지 않습니다.
번역되는 텍스트는 사용자가 고른 번역 서버로 전송됩니다. 그래서 로컬 서버는 모든 것을 PC 안에 두지만
클라우드 서버는 그렇지 않습니다.
