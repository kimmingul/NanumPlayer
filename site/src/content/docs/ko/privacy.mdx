NanumPlayer는 기본적으로 **무엇을 시청했는지 아무것도 남기지 않도록** 만들어졌습니다. 계정, 원격 측정(텔레메트리)이나 분석, 자동 업데이트 확인이 없고, 자체 서버도 없습니다. 이 문서는 저장소의 전체 [개인정보 문서](https://github.com/kimmingul/NanumPlayer/blob/main/docs/ko/privacy.md)를 요약한 것이며, 그 문서의 모든 내용은 소스 코드와 대조해 확인할 수 있습니다.

## 기본적으로 남기지 않는 것

직접 켜지 않는 한 다음은 디스크에 기록되지 않습니다. 재생 로그, 시청 기록과 이어 보기 위치, 방문한 주소, 번역 캐시, 자막 라이브러리, GPU 셰이더 캐시, 충돌 덤프.

전체 번역과 자막 가져오기의 작업 사본은 실행 중인 프로세스의 임시 폴더에 있습니다. 미디어가 끝나면 비워지고 플레이어를 종료하면 삭제됩니다. 자막은 다음에 영상을 재생할 때 다시 생성됩니다.

**저장되는** 것은 설정(`%APPDATA%\NanumPlayer`), 내려받은 음성 모델, 선택 구성 요소, 그리고 SRT 파일이나 MKV 저장본처럼 직접 만든 파일입니다. 용어집을 편집하면 작품 이름을 딴 텍스트 파일로 `%APPDATA%\NanumPlayer\glossary`에 저장됩니다. 무엇을 봤는지 흔적을 남기고 싶지 않다면 이 폴더를 삭제하세요.

## PC 밖으로 나가는 것

음성 인식은 내 PC에서 실행되며 NanumPlayer는 소리를 업로드하지 않습니다. 연결은 다음이 전부입니다.

| 언제 | 어디로 | 무엇을 |
|---|---|---|
| 번역할 때(켜져 있는 경우) | 내 **번역 서버**. 기본값은 내 PC의 `http://127.0.0.1:11434` | 번역할 텍스트. 용어집을 위한 작품 제목과 음성 언어 |
| 음성 모델을 내려받을 때 | Hugging Face(고정된 리비전) | 파일 내려받기. 크기와 SHA-256으로 검증 |
| cuBLAS를 내려받을 때 | 이 저장소의 GitHub 릴리스 | 파일 내려받기. 검증됨 |
| YouTube 도구를 사용할 때 | `yt-dlp`와 Deno의 GitHub 릴리스 | 파일 내려받기와 버전 확인 |
| YouTube와 웹 창 | 방문하는 사이트(WebView2 경유) | 시크릿 세션에서의 일반 브라우징 트래픽 |
| 온라인 영상을 재생할 때 | 해당 영상의 서버 | 미디어 요청 |
| 온라인 자막 찾기 | 내 브라우저가 OpenSubtitles 또는 Jimaku를 엶 | 제목을 검색어로 사용 |
| 선택 디스크 구성 요소를 설치할 때 | GitHub, 이후 동의하면 FindVUK 키 데이터베이스 | 파일 내려받기 |
| OCR 언어 팩을 설치할 때 | Windows(Microsoft) | Windows 자체 설치 프로그램 |

<Aside type="caution" title="클라우드 번역 모델">
  번역할 텍스트는 설정한 서버로 전송됩니다. 로컬 Ollama 모델을 쓰면 모든 것이 내 PC 안에 머뭅니다. Ollama **클라우드** 모델을 선택하면 그 텍스트가 클라우드 제공자에게 전송되므로 해당 제공자의 개인정보 약관을 읽어 보세요. 선택한 서버가 그 텍스트로 무엇을 하는지는 NanumPlayer가 통제할 수 없습니다.
</Aside>

## 시크릿 웹 세션

YouTube와 웹페이지 창은 항상 **InPrivate** 세션으로 실행됩니다. 로그인과 쿠키는 그 세션 동안만 유지되며, 세션이 끝나면(또는 **시크릿 웹 세션 종료 (로그아웃)**을 선택하면) 브라우저의 임시 데이터와 함께 삭제됩니다. 일반 웹 영상의 쿠키는 메모리를 통해 플레이어에 전달되며 그 파일에만 사용됩니다.

시크릿이 익명은 아닙니다. 웹사이트, 네트워크 관리자, 번역 제공자로부터 내 트래픽을 숨겨 주지 않으며, 운영 체제가 메모리를 페이징하거나 삭제된 파일이 복구 가능하게 남는 것도 막지 못합니다.

## 데이터를 남기는 옵션

직접 지정한 경우에만 해당합니다. `--log-file`(주소와 파일 이름이 들어 있을 수 있음), `--nanum-cache`, `--nanum-library-db`, `--nanum-full-dir`, `NANUMPLAYER_CRASH_DUMP_DIR`(덤프에 쿠키와 기타 메모리가 들어 있을 수 있음), 디스크 진단 로그(미디어 내용, 키, 드라이브 일련번호는 없음). 웹 영상은 지속 저장 옵션을 사용하지 않습니다.
