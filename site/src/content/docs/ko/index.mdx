## 알아 두세요

- **Windows 전용입니다.** AVX2를 지원하는 CPU의 64비트 Windows 10 또는 11이 필요합니다. NVIDIA GPU는 선택 사항이며 음성 인식 속도를 높여 줍니다.
- **번역 모델이 필요합니다.** 자막은 로컬 또는 클라우드의 Ollama 호환 서버가 번역합니다. [시작하기](getting-started/#번역-서버)를 참고하세요.
- **디스크 복호화는 별도의 선택 다운로드입니다.** 보호되지 않은 디스크, 폴더, ISO 이미지는 일반 설치 파일만으로 재생됩니다. [Blu-ray/DVD 복호화 구성 요소(선택)](disc-decryption/)를 참고하세요.
- **오픈 소스입니다.** NanumPlayer는 수정한 mpv(GPL-2.0-or-later)와 whisper.cpp(MIT)를 기반으로 합니다. [라이선스 및 고지](license/)를 참고하세요.
