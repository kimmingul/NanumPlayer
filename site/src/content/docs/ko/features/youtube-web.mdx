NanumPlayer는 로컬 파일과 같은 음성 인식, 번역, 용어집, 말투로 온라인 영상을 재생할 수 있습니다. 화면과 소리는 NanumPlayer에서 재생되고, 자막도 웹사이트 위가 아니라 NanumPlayer가 그립니다.

두 기능 모두 `nanum_youtube.exe`가 제공하는 작은 내장 브라우저 창(Microsoft **WebView2**, Windows 11에는 보통 이미 설치되어 있음)을 사용합니다.

## YouTube

<Steps>

1. **Ctrl+Y**를 누르거나 시작 화면에서 **YouTube**를 선택합니다. YouTube 창이 열립니다.
2. 평소처럼 둘러보고 로그인합니다. 로그인은 선택 사항이며 로그인이 필요한 영상에만 필요합니다.
3. 영상을 고릅니다. NanumPlayer가 창의 세션을 이용해 `yt-dlp`로 재생하고, AI 자막이 평소처럼 시작됩니다.

</Steps>

- **처음 사용할 때:** YouTube 도구(`yt-dlp`와 Deno)는 필요할 때 내려받습니다. 설치 파일의 선택 작업이나 **Ctrl+N → YouTube**에서 받을 수 있습니다. 내려받은 파일은 크기와 SHA-256으로 검증되고, 업데이트 확인을 제안하며, 취소 버튼이 있습니다.
- **주소 붙여넣기:** **Ctrl+N → YouTube 주소로 재생…**은 복사한 링크를 바로 재생합니다.
- **브라우저 북마크:** *Open in NanumPlayer* 북마크는 설치 파일이 등록하는 `nanumplayer://open?url=` 링크를 사용합니다.
- **자막:** 영상에 업로더가 제공한 자막이 있으면 음성 인식 대신 그 자막을 원문으로 사용합니다(메뉴에서 음성 인식으로 바꿀 수 있습니다). YouTube 자동 생성 자막은 요청하지 않습니다.
- 비공식 도구로 로그인하면 YouTube가 추가 확인을 요구하거나 접근을 제한할 수 있습니다. YouTube 이용 약관을 지켜 주세요.

## 웹페이지 영상

일반 사이트의 영상은 다음과 같이 재생합니다.

<Steps>

1. 시작 화면에서 **웹페이지에서 재생하기**를 선택하거나 **Ctrl+Shift+Y**를 누르거나 **Ctrl+N → 웹페이지 영상 주소로 재생…**을 사용해 페이지 주소를 붙여 넣습니다.
2. 열린 창에서 사이트가 요구하면 로그인하고, 페이지에서 **영상을 재생하기 시작**합니다.
3. 위쪽의 **NanumPlayer에서 재생**을 클릭합니다. NanumPlayer가 재생과 AI 자막을 이어받습니다.

</Steps>

NanumPlayer는 iframe 안의 영상과 HLS, DASH 스트림을 포함해 페이지가 실제로 불러온 미디어 주소를 감지합니다. 그 영상의 쿠키, Referer, User-Agent는 그 파일에만 적용되며 다음 파일로 이어지지 않습니다. 언어 태그가 없는 음성은 다국어 언어 감지로 시작하므로 다국어 음성 모델을 설치하세요.

### 동작하지 않는 경우

- DRM으로 보호된 영상.
- 재생 가능한 미디어나 매니페스트 주소를 전혀 노출하지 않는 사이트.
- 브라우저 밖에서의 재생을 거부하는 서버. 만료되는 주소는 페이지에서 다시 불러와야 합니다.

모든 사이트의 재생이 보장되는 것은 아닙니다.

## 설계부터 비공개

YouTube와 웹 창은 **항상 InPrivate 세션으로 실행됩니다**. 로그인과 쿠키는 그 세션 동안만 유지되며, 세션이 끝나면 브라우저의 임시 데이터와 함께 삭제됩니다. 일반 웹 쿠키는 메모리를 통해 플레이어에 전달되고, YouTube 쿠키는 세션이 끝나면 삭제되는 임시 파일만 사용합니다. 언제든 **Ctrl+N → YouTube → 시크릿 웹 세션 종료 (로그아웃)**으로 세션을 끝낼 수 있습니다.

<Aside type="caution">
  시크릿 세션은 익명성을 뜻하지 않습니다. 웹사이트, 네트워크, 번역 제공자는 여전히 볼 수 있는 것을 볼 수 있고, 운영 체제가 메모리를 페이징하거나 삭제된 파일을 복구 가능하게 남길 수 있습니다. [개인정보](/NanumPlayer/ko/privacy/)를 참고하세요.
</Aside>

웹 영상은 자막 라이브러리에 저장되지 않으며, 웹 영상의 전체 번역은 항상 임시 폴더로 갑니다.
