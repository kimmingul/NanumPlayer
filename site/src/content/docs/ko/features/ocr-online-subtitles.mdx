## 디스크 이미지 자막 (OCR)

Blu-ray(PGS)와 DVD의 자막은 그림입니다. NanumPlayer는 영상과 같은 읽기에서 이를 디코딩하고, 흰 바탕에 검은 글자로 바꾸고, 작은 글자는 키운 다음 **Windows OCR**로 읽습니다. 번들로 포함된 모델은 없습니다. 결과는 `한국어 (영어 디스크 자막 기반)` 같은 트랙이 되며, 시간은 디스크와 정확히 일치하고 디스크를 추가로 읽지 않습니다.

- 강제 자막이 아닌 영어 트랙을 우선합니다. 다른 언어는 해당 언어의 Windows OCR 팩이 필요합니다. [OCR 언어 팩](/NanumPlayer/ko/getting-started/#ocr-언어-팩-선택)을 참고하세요.
- 영어 팩이 없으면 설치된 라틴 문자 인식기를 사용하고 흔한 오인식을 보정합니다. 예를 들어 `50` → `So`, `tO` → `to`, `donlt` → `don't`입니다. 영어 팩을 설치하면 정확도가 높아집니다. 다른 언어용 인식기로는 일부 단어가 여전히 잘못 읽힐 수 있습니다.
- 이미지 자막 작업은 음성 기반의 주 자막 이후에 실행되며, 기본적으로 결과는 현재 재생 동안에만 유지됩니다. **Ctrl+N**에서 디스크 자막 OCR을 끌 수 있습니다.

## 온라인 자막

**Ctrl+N → 온라인 자막 찾기 (OpenSubtitles · Jimaku)**는 제목을 채운 OpenSubtitles(영어, 일본어, 한국어) 또는 Jimaku(일본 애니메이션)의 검색 페이지를 브라우저에서 엽니다. 주소 기반 검색이 없는 Jimaku는 첫 페이지를 열고 검색어를 클립보드에 복사합니다.

**자막은 직접 내려받습니다.** NanumPlayer는 이 사이트에서 클릭하거나 스크립트를 실행하지 않습니다. 그 뒤 다운로드 폴더(메뉴에서 변경 가능)를 20분 동안 지켜보다가 저장한 파일을 `.zip` 압축 파일까지 포함해 가져옵니다. **자막 파일 가져오기…**를 사용하거나 파일을 창에 끌어다 놓을 수도 있습니다.

가져올 때 NanumPlayer는 다음을 합니다.

- 인코딩(UTF-8, UTF-16, CP949, Shift-JIS, CP1252)과 언어를 감지합니다.
- 인식된 음성과 시간을 비교해 오프셋(최대 ±240초)과 속도 비율(23.976, 24, 25 fps 변환)을 자동으로 보정합니다.
- 신뢰도가 낮으면 추측하지 않고 알려 줍니다. 이때는 **가져온 자막 시간 미세 조정**(±0.1초 또는 ±1초)으로 바로잡으세요.
- 한국어 자막은 그대로 보여 주고, 다른 언어는 용어집과 말투를 적용해 번역합니다.

새로 가져오면 이전에 가져온 트랙을 대체합니다. 임시 작업 사본은 종료할 때 삭제되며, 내려받은 원본은 절대 삭제하지 않습니다. 다른 사이트의 자막은 표현과 편집이 내 영상의 버전과 다를 수 있어 자동 정렬이 덜 확실할 수 있습니다.
