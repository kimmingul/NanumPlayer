## 그 밖에 포함된 기능

- **여섯 가지 인터페이스 언어:** 영어, 한국어, 일본어, 중국어 간체, 중국어 번체, 스페인어를 플레이어, 설정, 브라우저 창, 설치 파일에서 지원합니다. **Ctrl+Alt+L**로 바꿉니다.
- **디스크를 MKV로 저장:** **Ctrl+B**는 Blu-ray나 DVD 타이틀을 재인코딩 없이 무손실 MKV 파일로 복사하며 음성, 자막, 챕터를 유지합니다. [Blu-ray/DVD 구성 요소](/NanumPlayer/ko/disc-decryption/)를 참고하세요.
- **기본 비공개:** [개인정보](/NanumPlayer/ko/privacy/)를 참고하세요.

## 키보드 단축키

| 키 | 동작 |
|---|---|
| Ctrl+N | 설정 메뉴(AI 자막과 그 밖의 모든 설정) |
| Ctrl+K | AI 자막 상태 |
| Ctrl+O | 파일 열기 |
| Ctrl+D | Blu-ray 열기 |
| Ctrl+A | 음성 트랙 |
| Ctrl+T | 자막 트랙 |
| Ctrl+B | 디스크를 MKV로 저장(Ctrl+C로 취소) |
| Ctrl+Y | YouTube |
| Ctrl+Shift+Y | 웹페이지에서 재생하기 |
| Ctrl+Alt+L | 인터페이스 언어 |
