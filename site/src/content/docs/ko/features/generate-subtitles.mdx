**Ctrl+N → 전체 자막 생성…**은 **자막 파일 만들기** 창을 엽니다. 로컬 영상이나 Blu-ray 타이틀의 완전한 SRT 파일을 **재생하지 않고** 만듭니다. 별도의 읽기 작업이 필요한 스트림 하나만 최고 속도로(화면도 소리도 없이) 가져오므로 지금 보고 있는 영상에는 영향이 없습니다.

## 소스 고르기

- **음성 인식:** 실시간 자막과 같은 엔진(CPU 또는 CUDA)으로 음성 트랙을 인식합니다.
- **텍스트 자막 트랙** 또는 외부 자막 파일.
- **이미지 자막(PGS/DVD) OCR:** Windows OCR을 사용합니다. [이미지 자막](/NanumPlayer/ko/features/ocr-online-subtitles/)을 참고하세요. 결과는 편집할 수 있는 SRT입니다.

## 결과물

NanumPlayer는 **원어 SRT를 먼저** 저장한 다음, 고른 **언어별로 번역 SRT를 하나씩** 저장합니다. 번역 서버, 모델, 말투는 설정에 있는 것을 따르며, 작품의 용어집은 번역 모델이 만듭니다. 소스와 이미 같은 언어는 번역하지 않습니다.

- 파일 이름은 `video-name.<language>.srt`이며 영상 옆에 저장됩니다. 디스크는 `%USERPROFILE%\Videos\NanumPlayer`에 저장되며, 원하는 폴더를 고를 수도 있습니다.
- 기존 파일은 **절대 덮어쓰지 않습니다**. 대신 번호(`.2`, `.3`)가 붙습니다.
- 각 파일은 `.part`로 쓰다가 완성되면 이름을 바꾸므로, 중단된 작업이 반쯤 쓰인 파일을 남기지 않습니다.
- 진행률과 경과 시간이 창과 알림에 표시됩니다. **취소**해도 이미 저장된 것은 모두 유지됩니다.
- **처음 10분만 (미리보기)**로 영화 전체를 처리하기 전에 OCR 팩과 번역 품질을 확인할 수 있습니다.
- 시작하지 않으면 아무것도 쓰지 않으며, 끝난 뒤에는 아무것도 기억하지 않습니다.

## 알아 두세요

- 디스크의 이미지 자막 OCR은 타이틀 전체를 읽어야 하므로 광학 드라이브의 속도에 제한을 받습니다.
- 웹 영상은 여기서 지원하지 않습니다. 재생하면서 실시간 AI 자막을 사용하세요.
- 스크립트로도 제어할 수 있습니다. `nanum-generate` 명령과 `user-data/nanum/generate` 속성이 상태를 보고합니다.
