대사를 한 줄씩 번역하면 이름이 틀리기 쉽습니다. 같은 인물이 세 가지 다른 표기로 바뀌곤 합니다. NanumPlayer는 작품별 **용어집**으로 이 문제를 해결합니다.

## 용어집이 만들어지는 방식

영상이 시작되면 번역 모델이 디스크 이름, 제목 태그, 파일 이름과 음성 언어 목록으로 작품을 식별합니다. 그런 다음 인물, 장소, 조직, 지어낸 용어의 용어집을 만듭니다.

- 원래 표기와 로마자 또는 영어 표기(두 가지 이름 순서 모두),
- 성, 이름, 전체 이름이 모두 **하나의** 번역 표기로 연결됩니다.

실시간 번역은 현재 줄에 나오는 항목과 주요 인물을 받습니다. 전체 번역은 용어집 전체를 받습니다.

## 검토하고 편집하기

**Ctrl+N → 용어집**을 열면 다음을 할 수 있습니다.

- 목록 보기,
- 항목 추가, 변경, 삭제,
- 메모장에서 한꺼번에 편집(저장하면 적용),
- AI로 용어집 다시 만들기.

이름 하나를 바꾸면 NanumPlayer가 같은 인물의 성, 이름, 전체 이름도 함께 바꿀지 묻습니다. 변경하면 그 이름이 들어 있는 **기존 자막을 다시 번역**하며, 두 트랙, 저장된 자막, 전체 번역 모두에 즉시 적용됩니다.

<Aside type="caution">
  용어집의 품질은 번역 모델에 달려 있습니다. 작은 로컬 모델은 항목을 지어내거나 모르는 인물의 이름을 잘못 적을 수 있습니다. 목록을 확인하세요. 특히 AI가 잘못 들은 소리를 바탕으로 적은 이름을 살펴보세요. 클라우드 모델은 작품을 훨씬 잘 알아봅니다.
</Aside>

## 번역 말투

**Ctrl+N → 번역 말투**는 번역이 어떤 말투를 쓸지 정합니다.

| 말투 | 의미 |
|---|---|
| 자연스럽게(기본) | 인물 사이의 관계에 맞게 존댓말이나 반말을 일관되게 유지합니다. |
| 존댓말 | 항상 존댓말을 씁니다. |
| 반말 | 항상 반말을 씁니다. |
| 원문에 충실 | 원문 표현에 최대한 가깝게 번역합니다. |
| 직접 입력 | 직접 쓴 지시문입니다. 예: "아이에게 말하듯 다정하게". |

말투는 다음에 번역되는 줄부터 적용되며, 이미 만든 자막은 그대로입니다. 캐시된 번역은 말투와 용어집별로 구분됩니다.

## 로컬 모델 출력 복구

일부 로컬 모델은 한국어를 `<0xED><0x9B><0xA0>` 같은 바이트 토큰으로 출력합니다. NanumPlayer는 이를 올바른 UTF-8 텍스트로 복원하며, 복원할 수 없는 줄은 번역 실패로 간주해 저장하지 않습니다.
