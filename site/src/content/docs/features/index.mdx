## Also included

- **Six interface languages:** English, Korean, Japanese, Simplified Chinese, Traditional Chinese and Spanish, in the player, the settings, the browser window and the installer. Switch with **Ctrl+Alt+L**.
- **Save discs to MKV:** **Ctrl+B** copies Blu-ray or DVD titles into lossless MKV files (no re-encoding), keeping audio, subtitles and chapters. See [Blu-ray/DVD components](/NanumPlayer/disc-decryption/).
- **Privacy by default:** see [Privacy](/NanumPlayer/privacy/).

## Keyboard shortcuts

| Keys | Action |
|---|---|
| Ctrl+N | Settings menu (AI subtitles and everything else) |
| Ctrl+K | AI subtitle status |
| Ctrl+O | Open file |
| Ctrl+D | Open Blu-ray |
| Ctrl+A | Audio track |
| Ctrl+T | Subtitle track |
| Ctrl+I | Picture quality (upscale and correction) |
| Ctrl+B | Save disc to MKV (Ctrl+C cancels) |
| Ctrl+Y | YouTube |
| Ctrl+Shift+Y | Play from a web page |
| Ctrl+Alt+L | Interface language |
