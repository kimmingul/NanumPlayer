## NVIDIA cuBLAS

The optional cuBLAS download (`cublas64_13.dll`, `cublasLt64_13.dll`) is NVIDIA software and is subject to NVIDIA's CUDA redistribution terms, which you must accept before NanumPlayer downloads it. If you already have a CUDA 13 Toolkit installed, NanumPlayer uses its files in place and nothing is downloaded.
